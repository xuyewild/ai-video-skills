# 动作物理与编排

AI 视频里的打斗最容易出三种废片：拳穿过身体、打完没人动、两人摆好架势互相等。原因几乎都在提示词：只写了“激烈交手”“一拳把他打飞”，模型只拿到开头和结局，过程靠它自己编。

这个 skill 把动作拆成模型能执行的因果链：**谁用哪只手从哪起手 → 碰到对方哪里 → 对方往哪退、落在哪、靠什么停住**。它来自半年 AI 漫剧生产里几百条打斗镜头的返修记录，加上动作设计行业的通用手艺。视频写法以 Seedance 2.5 为例，原则对其他视频模型同样适用。

## 什么时候用

| 用 | 不用 |
|---|---|
| 摔投、擒拿、兵器（含交接、夺取）、两人以上真实接触、高差与坠落、人与动物或怪兽互动（扑、抓、托、骑、甩）、伤后受限动作、群战局部、追逐、Q 版夸张打斗 | 走位、转头、递东西、坐下；剧本已写清的简单动作 |

## 输入

当前场次的动作原文；参与者、能力、伤势；角色的体型和相对身高（人与动物互动必读，有视觉圣经就取“尺度基线”）；场景方位；承接上一条视频时，上一条的结束画面。缺伤侧、尺寸或方位且会改变动作时，列出缺口，不编。

## 不管什么

胜负与落点、伤势事实、人物弧光、作者锁定的台词、景别和镜头方案、特效怎么扩散和消散。打法（谁先出手、用什么招、借什么地形）可以重新设计，见 [body-and-contact.md](references/body-and-contact.md) 第 19 节。

## 输出两种写法

**写剧本时：过程链正文段**——按 准备 → 接触（抓哪、踩哪）→ 发力 → 重心 → 路径 → 惯性 → 受力结果 → 余势（头发、衣摆、道具）写一段自然中文，直接替换原来的动作句。冲锋的人不停下等台词；有能力救场的人要有效行动。

段首加 `【动作段】` 方便检查，写回剧本时去掉标记，段内不留空行。

**写视频提示词时：逐拍动作块**，每个动作拍一块：

```text
【动作】<名称>｜片段<N>秒｜第<k>/<M>拍
起手：<谁、哪只手/脚、往哪蓄力>（一句）
接触：<哪个部位碰到对方哪里>（一句）
结果：<被打的一方怎么动、落在哪、什么姿态、地上留下什么、靠什么稳住>（一句）
碰撞：<轻 / 重 / 大招>｜环境：<受力怎么传出去：脚下 → 地面 → 近处的物体>｜镜头：<轻轻一震 / 明显晃动 / 剧烈晃动 / 不震>
受力方向：<从画面X向画面Y / 向后上方>
镜头配合：<切镜：拆 2–3 个短镜，逐镜写景别、运镜、谁是主体；或一镜到底：一行一回合，写运镜和震动档>
```

一拍 = 起手-接触-结果。“片段”是一次生成的视频长度。“碰撞”行只用来定反馈强度，写进提示词时只写看得见的反馈，不写“重”“大招”这类标签。动作块是设计稿，最终提示词里把三句并进镜头描述，标签去掉。

范例见 [action-templates.md](references/action-templates.md)。

## 动作类型

| 类型 | 必写 | 最常见失败 |
|---|---|---|
| 徒手 | 支撑脚、出手侧、命中部位、打完的回收 | 拳穿过身体、打完没人动 |
| 兵器 | “双手握刀”写进主体；刃线方向；一种出招（只劈或只刺） | 武器消失、变形、换手 |
| 摔投 | 抓握点 → 破坏重心 → 一种发力（抡/背/绊）→ 落地顺序 | 没抓就飞、落点无来源 |
| 追逐 | 双方方向、谁快谁慢、地形障碍 | 背景动人不动、主角变慢动作 |
| 高差坠落 | 失去什么支撑 → 下落 → 先着地的部位 → 停姿 | 凭空下坠、空中变向 |
| 人与动物、怪兽 | 相对身高（写数字）；抓、托的具体部位；谁承重 | 尺度漂移、手穿进毛里、动物变小 |
| 群战 | 一拍只一对主接触；其余人各做一件事 | 全员乱打、复制人、穿插穿模 |
| Q 版夸张 | 标进标出；夸张靠形变和停顿，不靠加招 | 比例不切回、Q 段写太多招 |

身体怎么动的完整清单见 [body-and-contact.md](references/body-and-contact.md)。

## 写给视频模型的 14 条规则

依据和原话见 [seedance-rules.md](references/seedance-rules.md)、[sources.md](references/sources.md)。

1. **先因后果**：按起手 → 接触 → 结果写全，不能只给开头和结局——只给首尾，模型会自己编过程。
2. **拍长由动作决定**：拍是动作不是镜头，一拍可以切几镜，最短约 0.25 秒；一个时间段一个主动作；打斗、特效连锁可以连写 2–3 个，日常镜头一镜一件事。
3. **受击看得见受方**：受方是画面主体，机位在正面或侧面，从接触那一下起幅，写成有先后的位移；冲锋不停在接触前等台词。
4. **方向写具体**：“从画面右向左横劈”，全段方向锁定一致。
5. **意图写明**：攻击还是防御；只写“不躲不挡抬掌”会被模型补一个护盾。
6. **快动作会糊**：只在最快一下允许运动模糊，写“动作结束后脸、手、武器立即恢复清晰”；用简单招式。
7. **多人接触是弱项**：一拍只一对接触，接触前写清两人距离和各自用哪只手。
8. **慢动作只给决定性一拍**：标进标出，写其他人“保持正常速度”；不标会出现主角单独慢放。整镜所有人同速的整段慢放可以例外。
9. **镜头跟着事件动**：运镜由动作触发（“刀落下时镜头快速下摇跟到刀尖”）；同一镜可以复合运镜，按先后写。
10. **结果词不堆**：“狠狠地”“巨大冲击力”换成部位、方向、位移、落点。
11. **承接写进行时**：承接上一条时写“正在向左滑出半步”，不写成新一招；否则模型会重演或卡顿。
12. **结果写到痕迹和停法**：“倒滑三步，靴底犁出两道沟，蹬住石柱稳住”；强弱靠位移差（“连退五步”对“后滑三步”），同一击两种反应（“甲跪地，乙不动”）。
13. **有轻有重、有目的**：接触分轻、重、大招，大部分是轻和重；镜头只在接触那一下沿受力方向震，留不震的拍。每一击写目的（封路、逼对方换方向、打断蓄力）。
14. **力量来自时间反差和受方**：蓄力慢、出手快、受方反应大，攻方也受反震；险躲留小证据（削断一缕头发）；开场就在交手，反冲就是下一招的起手；按动作、镜头路线、周围反应三件事写，也按三件事查。

## Seedance 2.0 的差异

2.0 单条 4–15 秒；双人交手拆成攻方一镜、受击一镜、反击一镜，能拆成几条就拆；约 5 秒一拍，一条一个主招式；动作较锐利，但拳穿过目标常见，命中写成单独一镜。

## 自检

1. 每个动作拍都有起手、接触、结果三句，且按这个顺序；关键接触拍过“七问”（body-and-contact 第 19 节）。
2. 每拍写了受力方向，方向与全段锁定一致。
3. 受击方是受击镜的主体、看得见、从接触起幅，有位移落点；冲锋没停在接触前；起手只写一次。
4. 武器写进主体，持有手、刃线全程不变；交接写出两人同时握住再松手。
5. 人与动物互动写了相对身高和承重点。
6. 伤侧不承重、不出全力，代偿看得见。
7. 没有无过程的结果词；结果写到位移、痕迹和停法；接触有轻有重，震动只在接触那一下。
8. 慢动作、Q 版都有标进标出。
9. 对设计稿运行检查脚本无错误（只查写法，不判断物理是否合理）：

   ```bash
   python3 scripts/validate_action_text.py 设计稿.md            # 查【动作】【动作段】块
   python3 scripts/validate_action_text.py 剧本片段.md --prose   # 没加标记的正文段也查
   ```
