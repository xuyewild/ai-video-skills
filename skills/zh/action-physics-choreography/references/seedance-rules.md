# 视频模型动作写法规则（以 Seedance 2.5 为例）

联网资料与作者生产实测的归纳。编号对应 [sources.md](sources.md)。标“判断”的是没有直接资料、按身体力学或经验写的。其他视频模型的硬限制（时长、参考图数量）以各自官方文档为准，写法原则通用。

## 一、写法规则（2.5）

| # | 规则 | 依据 |
|---|---|---|
| 1 | 按起手 → 接触 → 结果写全，结果放最后；不能只给开头和结局（只给首尾，过渡由模型乱编） | S9、S10、S2 |
| 2 | 一个时间段一个主动作；时间段内容过多会过度剪切或丢拍；事件密就减少阶段，不往细切。打斗例外：一镜可连写攻守位移 2–3 个动作（先……随即……再……）；特效连锁镜头同理；非对白的日常镜头一镜一件事、写完就切；对白镜头仍一个主动作 | S1、S6、S11、S2；打斗例外来自第三方样本 |
| 3 | 拍数不设上限，拍的多少由动作和镜头需要决定；S7、S6 只给出节拍密度的观察，不折算成公式 | S7、S6 |
| 4 | 一拍（起手-接触-结果）时长由动作需要决定，最短约 0.25 秒；时间戳可写到 0.25 秒。打斗切镜不设镜长下限 | 判断（S8 的快切示例平均 1.25 秒是切点，不是一拍） |
| 5 | 重要动作写方向、距离、速度、接触、反应；背景动作不必写 | S7 |
| 6 | 打击要有重量：反冲、随势、受击方被推开；不要“飘” | S8、S4 |
| 7 | 快动作会糊、会变形：只让最快一下带方向性模糊，写“动作结束后脸、手、武器立即恢复清晰”；用简单招式代替“旋转跳跃连环踢” | S12、S13；简单招式见 S19（2.0） |
| 8 | 多人接触、复杂动作物理是官方承认的弱项：一拍只一对主接触；接触前写清距离、各用哪只手 | S3 |
| 9 | 武器写进主体，锁定一种出招（只劈或只刺）、刃先到；约束写“武器不漂浮” | S8、S10、S19 |
| 10 | 慢动作只给决定性一拍（约 2 秒），标进标出，写其他人“保持正常速度”；定格、子弹时间、全屏白闪每条视频各最多一次 | S8、S4、S14 |
| 11 | 运镜由动作触发；同一镜可以复合运镜，按先后写；动作戏可用甩镜接下一次交手 | S1、S10、S4 |
| 12 | 动作不全写成“同时”；真同时才写“与此同时” | S10 |
| 13 | 承接或延长时写正在进行的运动，不把上一拍再写一遍 | S10、S16 |
| 14 | 30 秒长段每一段都要有新的状态变化（新接触、换方向、换高度、有人倒下），否则后半段单调 | S15 |
| 15 | 群战背景人物拉开间距、不出现复制人；每人在画面里只出现一次；主体 1–8 个最稳 | S4、S8、S6 |
| 16 | 结果词换成过程：“狠狠地”“猛地”“巨大冲击力”换成部位、方向、位移、落点 | S5 |
| 17 | 受击方在受击镜头里是主体；只写“命中”“光”会得到不动的身体；大型静态结构的整体位移单独写一条，还不动就改成崩解 | S18 |
| 18 | 攻击还是防御写明；只写“不躲不挡”会被补出护盾 | S18 |
| 19 | 动漫强化风格：冲击帧、速度线可写，风格锚点不超过两个；画风以视觉圣经为准，3D 项目不写成纯 2D 赛璐璐，2D 项目也不写体积光和写实材质 | S17、S4；后半句为判断 |
| 20 | 人与动物互动：相对身高写数字，挂尺度参照图；接触部位写到具体结构 | 判断（查不到专门资料） |
| 21 | 结果写到痕迹和停法：受击方滑退几步、脚下犁出什么、靠什么稳住 | S21；与规则 6、17 一致 |
| 22 | 强弱靠位移差（一方退五步、一方退三步）和同一击的两种反应（一个跪地、一个不动），不靠形容词 | S21 |
| 23 | 碰撞分轻、重、大招三级，每级配固定的身体、环境、镜头反馈；一条视频大部分是轻和重 | S21 |
| 24 | 镜头震动只在接触那一下、沿受力方向、随即回正，留不震的拍；不全程摇晃 | S21 |
| 25 | 攻击写目的：封路、逼对方换方向、打断蓄力 | S21 |
| 26 | 按方向、距离、速度、接触、反应写动作；用具体招式名（“右直拳”“双小臂格挡”），不写“迅捷”“史诗” | S22、S23 |
| 27 | 第一镜全景交代站位（打斗例外：第 0 秒就在交手，左右站位写进人物关系部分，中段用一次顶视或远景重新交代）；同一时刻一人主动；人物易粘连时把初始间距拉大 | S23、S25 |
| 28 | 变速写明在哪一刻转入慢动作、何时恢复；切换点不一定准，慢动作词只写一次 | S24 |
| 29 | 接触瞬间的“顿一下”写成可见状态（“两人连同火星一起顿了一下”），不写帧数；可能整段冻住，待验证 | 判断；S24 的冻结风险 |
| 30 | 冲锋和出招不停在接触前：镜头、视频都不落在“拳离胸口只剩一步”“扑在半空”上去等别的事；要插台词或别人的动作，先按距离算时间，装不下就把冲锋起点拉远、台词挪到起冲前，或压在冲刺中交叉剪，每次切回攻方都更近，接触落在最后一句台词上 | 作者实测：攻方冲到一步外停住摆架势，等约 10 秒台词才出拳 |
| 31 | 受击镜看得见受方：接触那一镜机位在受击方正面或侧面，过肩只越过攻方的肩；受击镜从接触那一下起幅（接触 → 受力 → 位移开始），不从“已在半空”开始 | 作者实测：机位越过受方的肩看攻方，成片攻方对空出拳、受方不动；下一镜从“倒飞，离地一人高”起幅，飞出的原因没拍 |
| 32 | 同一下只写一次、位置不写死：起手、收拳、松手、刹停、落地在相邻镜头和跨条只写一次，承接写“正在……”；不写被打的人“一直在某处”，写“开场在……，被打后停在……”；打飞方向、撞到的东西和场景站位对得上 | 作者实测：同一次收拳写了两遍；倒飞撞上的台阶其实在攻方一侧 |

## 二、已知失败与对策

| 现象 | 版本 | 对策 |
|---|---|---|
| 手臂被躯干挡住、消失 | 跨模型参考 S28（Wan 3.0 / MiniMax，非 Seedance） | 关键接触用侧面角度，写“全身在画面内、四肢不被躯干挡住” |
| 镜头在接触那一下躲开 | 跨模型参考 S28 | 镜头停在接触点，写“镜头不移开” |
| 快速段衣袍、肢体、刃口发软 | 2.5 实测 S12 | 规则 7；拍数减少；动作后停一拍 |
| 快速段肢体形变、多出肢体 | 2.5 实测 S13、S6 | 简单招式；写“手脚数量正常、不变形” |
| 拳、刀穿过目标（穿模） | 2.0 参考 S19；2.5 官方案例列为要避免 S4 | 命中单独一镜；写接触部位和受击方位移；两人距离先写清 |
| 武器换形、消失 | 2.5 实测 S12；2.0 参考 S19 | 武器写进主体；锁定持有手和刃朝向 |
| 主角像慢动作、旁人正常速度 | 2.5 实测 S14 | 不需要慢动作时写“全程正常速度”；需要时只标一拍 |
| 30 秒打斗后半段单调 | 2.5 实测 S15 | 规则 14 |
| 延长段不接上一段动作 | 2.5 实测 S16 | 开始画面写正在进行的运动方向和姿态 |
| 受击方不动、只出一条光 | 2.5 实测 S18 | 规则 17、31 |
| 方向写反、前后矛盾 | 2.5 实测 S18 | 每拍写受力方向，全段核对一次 |
| 自动加护盾 | 2.5 实测 S18 | 规则 18 |
| 多参考时重复人、串人 | 2.5 官方 S6 | 每张参考图逐行写清用途 |

## 三、动作块怎么并进视频提示词

- 动作块的“起手、接触、结果”三句，放进对应镜头的描述；“受力方向”写进人物关系或方向锁定的那一句；“镜头配合”是建议，镜头最终由写提示词的人定。
- 一拍跨两个镜头时（起手一镜、受击一镜），把“接触”写在受击镜头里，受击方是主体。
- 特效与动作在同一下：动作写到“接触点、方向、身体第一反应”，特效过程另写，合并成同一个事件。

## 三A、生成调试顺序

先用固定广角验证编排对不对，再加运镜；每次只改一个变量；只重写断掉的那一拍，不整段推倒（S23）。出错先查：空间是否冲突、接触是否写清、一条里塞了几个互相竞争的任务、对白是否占掉动作时间、参考图是否绑错。

## 四、Seedance 2.0 的其他差异

| 项 | 2.5 | 2.0 |
|---|---|---|
| 时长 | 4–30 秒 | 4–15 秒 |
| 风格 | 更贴近写实 | 更愿意做风格化变形 |
| 参考图 | 多 | 更少，人与动物同框时尺度参照图优先保留 |
| 提示词 | — | 两边写法不直接互搬 |
