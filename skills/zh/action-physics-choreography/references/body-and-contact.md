# 身体与接触

写动作段前用来想清楚身体怎么动。这里是“想”的清单，不是要全部写进提示词：写进提示词的只留起手、接触、结果和方向（见 SKILL.md）。

## 1. 每个动作先回答五件事

“起手”就是行业里的预判（telegraph）：出招前的蓄力动作要让观众看得见，否则出招像凭空发生。它和起手是同一件事，不另起一行，写进起手那一句即可。

| 问题 | 写进正文的样子 |
|---|---|
| 力从哪来 | 后脚蹬地、腰往左拧、兽后腿一蹬 |
| 碰到哪里 | 右拳打在左肋、左手扣住兽角根部 |
| 谁承重 | 他右脚钉在地上撑住两个人的重量 |
| 往哪去 | 向画面左后方滑出三步 |
| 停在哪、什么姿态 | 单膝跪地、左手撑地，刀尖还指着对方 |

## 2. 承重与重心

- 支撑换手要有中间状态：原支撑 → 共同或临时支撑 → 新支撑。
- 出拳、出腿：一只脚承重，腰胯先转，肩再送手；只甩胳膊没有重量。
- 膝击、高踢时另一只脚必须还在地上。
- 空中不能凭空变向，除非有已成立的能力、外力或抓到东西。
- 地面急转要有落脚和蹬地；湿滑、冰面要写打滑、压低重心或抓住东西才能停。
- 高差：每一级台阶、每一次落脚都真实踩到；谁在上、谁在下写清。

## 3. 接触与受力

| 接触类型 | 必须看得见的 |
|---|---|
| 实打 | 接触部位、受击方被推开的方向和距离，打人的一方跟着往前或收回 |
| 格挡 | 格挡面（刀身、小臂）、承压后退半步或刀被压偏 |
| 擦过 | 沿表面滑开，两人都偏离原线 |
| 落空 | 能看到空隙；出手的一方冲过头、要调整脚步收回；躲的人是自己躲开，不是被打退 |
| 撞环境 | 先接触，再碎裂或凹陷，最后碎屑 |

- 受力后退和自己后撤分开写。
- 反作用不消失：推人的人自己也会晃一下或要站稳。大招出手的人脚下也要有反应：地面压下一圈、被反冲推退半步。
- 受力写到痕迹和停法：退几步、脚下留下什么（犁出的沟、拖出的水痕）、靠什么停住（蹬住石栏、刀插进地里）。
- 拆招一一对应：攻方几下，守方就有几个对应的挡法，每一挡写清挡在哪、怎么偏开（“第一刺虚晃面门，第二刺取腹部；斧身倾斜擦过第一刺，斧柄压下第二刺”）。不写“连挡数招”。
- 同一处连击要递进：每一下比上一下更深（切进半寸 → 一寸 → 整块裂开），观众看得出是在破防，不是乱打。
- 借力：借对方前冲的惯性踢翻、摔出，比原地硬推更省力也更可信。
- 无血受击：用护体罡气碎散、甲片崩飞、衣料撕开、被打退的距离代替出血。
- 一下打完，两人都不回到原来的站姿，下一拍从这一拍的结果开始。

## 4. 抓握、摔投、托举

1. 先建立抓握点：抓衣领、扣手腕、抱腰、抓兽角或颈毛。
2. 再破坏对方重心：拉、推、绊、扛起。
3. 只选一种主发力：抡、背、绊、抛，不叠。
4. 被摔的一方按能力做反应：抓衣服、收腿、撑地。
5. 写清松手时机：松手后对方不会再自己加速。
6. 落地按“先着地的部位 → 滚或滑 → 停姿”写。

托举与骑乘：谁托谁、托在什么部位、托的人膝盖弯没弯；骑在兽背上抓哪里、腿夹在哪。

## 5. 武器与道具交接

- 武器写进主体：“双手握着长刀”，不写“带着刀”。
- 锁定持有手、刃朝向、长度；左右双持不交叉换手。
- 贴手交接或夺取：原持有 → 另一人碰到 → 两人同时握住 → 原持有者松手 → 新持有者握稳，再开始下一个动作。
- 抛接或掉地再捡：离手 → 飞或落地 → 接住或捡起 → 握稳。
- 长柄武器：尖、两手握点、尾端扫过的空间一起写；进到近身后要换握或后撤，武器不会自己变短。
- 已断的武器后面不复原，不握不存在的部分。

## 6. 坠落与落地

失去什么支撑 → 重心越出脚下 → 下落 → 先着地部位 → 滚翻消化或撞停 → 停姿。从高处落下写三步：先着地的部位砸出痕迹（膝下一圈裂纹）→ 顺着冲力滑出一段才稳住 → 留下磨损（膝盖处的布磨破）。滚翻方向跟原来的冲力方向一致。悬挂：抓点 → 身体荡 → 脚找支点 → 拉回或松手。

## 7. 兽人互动

- 先取角色设定里的相对身高（有视觉圣经就取“尺度基线”），能挂尺度参照图就挂（如“灵狐站直到主角膝盖”），每个同框动作都按它写距离和接触部位。
- 兽扑人：后腿蹬地 → 前爪先落在人哪里 → 人被压倒的方向 → 兽的体重落在哪。
- 人摔兽：抓兽身上真实存在的结构（角、颈甲边缘、前腿），说明人用什么撑住兽的重量；重型兽要写人的脚下滑、地面受力。
- 小兽在人身上：落在肩上、手臂上要有爪子抓布料、身体压低。
- 兽的毛、甲、翼在接触时有形变和余势；人的手不穿进毛里。

## 8. 群战

- **场景分割、逐个击破**：用长廊、门洞、竹林把敌人隔开，一个空间只放一个对手，正好对应“一拍一对主接触”（《镖人贰》请影视动作指导拍打戏的做法，澎湃 2026-06-14）。
- 每一拍只选一对主接触；其他人各有一件事：逼近、等待、挡路、恢复、退出。
- 换人进攻要有原因（被前一下推开了位置、看到空当）。
- 包围不等于排队挨打，也不等于全员同时乱打。
- 一个局部动作只改变附近几个人；远处的人只改变路线或姿态。
- **敌人不站着围观**：近处的被打退，中远处的立刻补上来；有人翻滚闪避，有人包抄、追击；大招期间敌人仍在移动（第三方样本，S30）。
- **敌群按种类分工**：怪物潮、杂兵群不写成同一种扑法——远程的喷火、投掷压制，巨型的掷石砸地压阵，小只的近身扑咬，精英几个合力打出一发大的；主角的回应跟着变：劈开飞来物、在轰炸里折线闪避、打断合击（S33）。

## 9. 伤后受限

- 伤势取剧本或设定，不新增、不加重、不突然痊愈。
- 写成功能限制：哪一侧不能承重、不能握紧、不能抬过肩。
- 代偿要看得见：换手、拖着腿、靠墙、靠同伴；动作慢半拍，恢复更久。
- 受伤会改打法：护着伤的那一侧出招、换手，或者反而更近、更狠、更急（第三方样本 4 份）。下一拍就写出来，不只当连续状态记录。
- 两人搀扶：谁承担主要体重，步子要合上，转弯时一起转。

## 10. 载体、绳索与物理触发

- 在移动的车、船、兽背上：先写载体怎么动，再写人相对载体怎么动；载体急停或急转，人和松动物件一起往惯性方向甩。
- 绳索：要有锚点；绳子先绷直才传力；荡的弧线绕着锚点。
- 能力或特效的物理触发：动作只写到“出手、接触点、方向、身体第一反应”，特效怎么扩散、多亮、何时消散交给特效设计。

## 11. 动作好看：线条、弧线、余势、亮相

动作设计行业的通用手艺（来源见 sources.md“动作设计手艺资料”），写成提示词时只留看得见的结果。

- **一条动作线**：出招时全身沿一条主线舒展（后脚、腰、肩、手、兵器连成一条弧），比四肢各动各的好看。
- **走弧线**：挥砍、踢腿、转身的轨迹写成弧（“刀从右上划出一道弧落到左下”），直线只给直拳、直刺。
- **余势晚一拍**：身体停了，衣摆、头发、发带、兵器穗子晚一拍才落下。每个重要动作结尾写一句。
- **剪影可读**：关键招式的姿态拉开四肢、侧对镜头，只看轮廓也认得出是什么招。别让手臂挡在身体前面。
- **收招亮相**：一段打完，人物停在出招终点或收势的造型上，保持一拍再动（“停在出剑的终点不动”）。按档区分：写意档用亮相（停在姿势上约一拍，衣摆最后落下）；写实档改成“稳定终态”——停在出招终点、喘气，不摆造型（Higgsfield 2026-08-13：写实打斗“不是戏剧化、不是吊威亚式摆姿势”）。
- **张弛**：快攻几下 → 短停（对峙、喘气、换架势）→ 再爆发。不全程同一速度。
- **兵器即性格**：长刀大开大合，短剑贴身快刺，双锤沉重，扇子轻巧转折。人物的打法要和性格、兵器一致，不同人物的招式写出区别。

## 12. 力量感与打击感

- **时间反差比快更有力**：慢慢蓄力 → 身体几乎停住 → 肢体或兵器猛地出去。出手和转体同时发生，招式会快但不重。写成“左膝提起停半拍，旋腰侧踹”。
- **受方卖出来**：打击感主要看受击的一方，姿态变化幅度跟力量成正比：头甩出去、身体对折、双脚离地、撞断身后的东西、落地翻滚。受方不反应，攻方再用力也没感觉。
- **接触那一下顿住**：接触瞬间写“两人连同飞溅的火星一起顿了一下”，再写受方被弹开（待验证：可能整段冻住）。不写“顿帧 2 帧”这类帧数。
- **反弹和反作用**：兵器相撞后双方手臂一顿、剑身发颤；借反弹的力压下一招。出手的人自己也要站稳。
- **小动作换大结果**最显强：轻轻一刀，身后一排竹子齐腰断开、慢半拍才倒。出手的人越强身体越省力：幅度小、躯干稳、神情和呼吸不变，威力交给特效和受方（S32；2.5 成片里单手短幅横斩接纵切，在同一个特写里拍出来了）。
- **声音**：大招前静一拍；接触是低沉的闷响加一声清脆的高音（金属、骨节），按材质写（木、石、金属、肉）。声音跟碰撞分档：轻碰短促清脆、一下就停，重碰闷响叠低频再一下余震，大招抽空一拍再音爆、最后留碎石落地这类小声音。人也要出声：喘息、闷哼、咬牙吸气、衣料猛甩、脚下碎石。
- **逐场升级**：受方位移、环境破坏、声音层次一场比一场大，最大的留给最后。
- **镜头少震**：清楚比晃更重要；轻碰至多轻轻一震，重碰明显一沉，大招峰值剧烈震荡一两下，每场有意留不震的镜头。

## 13. 一段打斗怎么排

- **先交代站位**：第一镜全景，看清两人距离、谁在哪边、周围有什么能用的东西。
- **同一时刻一人主动**：一对一时轮流主动；多人时对手依次上，不一起扑。
- **结构（五段，起承转合）**：原稿的打斗再笼统，也写成一个完整过程，有看点有爽点。推荐的默认排法：主角先被压着打（可以从试探、互相摸底开始，很快落下风）→ 在战斗中找反制措施 → 反制发现作用不大 → 陷入致命危机 → 关键助力或底牌出现、反败为胜，升级到收招亮相。反转点可以利用环境或对方的习惯；每一招都回答“为什么出这一下”。小冲突也要有来有回、有打击感，对手要显得强。**落点以原稿为准**：原稿主角赢的走满五段；原稿主角输、平手、被打断的，五段排到“致命危机”或原稿的落点为止，不改胜负；小冲突只要求有来有回，不要求五段。
- **劣势开场更好看**：主角先吃亏，赢得才有分量；痛的反应让人物像人。
- **先看参考**：设计前先看手上优秀的打斗和特效参考片，照人家的设计学。
- **动作和反应同框**：接触的那一下，攻方和受方尽量在同一个画面里，观众看得清谁打了谁。
- **一拍一对接触**：多人合击写成接力，同一时刻只有一处接触（扫腿逼对方起跳 → 同伴踩肩腾起 → 在最高点一掌拍下）。
- **拆成三件事写，也按三件事查**：人物的动作、镜头的路线、打中以后周围怎么反应。出片后卡在哪一项，就改哪一项的描述（S29）。
- **开场就在交手**：第一瞬间就已经在战斗里，写“主角已经在格挡反击”，不先摆姿势（S29）。
- **招和招接得上**：上一招收势的时候，下一招已经开始，比如“挡开 → 借力侧滑 → 在侧滑中反击”。重点看两招之间有没有停住重新摆姿势；接不上就减少招式，先把一组攻防做顺（S29）。
- **速度感靠具体的移动方式**：贴地滑行、低空助推、瞬步，每次都写方向和落点。写了滑行就检查人有没有贴近地面，助推的方向和移动方向是否一致（S29）。
- **两个对手打法不同**：一个始终前压、贴身硬切，一个边退边控场、找机会反压；整段打斗里这层关系不变（S30）。
- **官方的写法原则**：优先写概括性的动作，比如“双方展开近身搏斗”，只给少数有记忆点的动作写细节，不重复写相同的动作（S1）。作者只把这条用在陪衬、不展开的打斗；主打斗每拍写全。所以招式名词表（第 15 节）只用在要记住的那几下。有一份第三方样本写“1 秒最多 3 个动作”，只有这一份，当每秒动作数的上限参考。

## 14. 行话→画面（设计时用，提示词里写画面）

武术指导和动作导演的行话只在设计时用；写进提示词一律换成看得见的画面。来源见 sources.md“动作设计手艺资料”R 系列。

**先定这一场是写实档还是写意档**（香港武打片的老分法，HK01 2018/2025）：

| 档 | 画面 | 写法 |
|---|---|---|
| 写实 | 动作贴近真实拳种，不腾空、不摆造型 | 写具体招式和真实距离；写“没有吊威亚那种飘浮感” |
| 写意 | 为镜头好看，可以腾空、亮相 | 腾空写全：起跳点 → 最高点 → 落点；同一部戏里人对妖写实、神魔对决写意，可以分档（澎湃评《雾山五行》2020） |

| 行话 | 画面 | 提示词怎么写 |
|---|---|---|
| 北派 | 大开大合、伸展、翻腾 | 大弧线、全身舒展、空翻，两人距离拉开 |
| 南派 / 短打 | 用前臂近身短打 | 两人相距一臂以内，小臂相格，步子小 |
| 硬桥硬马 | 马步扎实、前臂硬碰 | 双脚钉在地上不离地，小臂对撞，上身不后仰 |
| 桥手 | 用前臂接触 | 前臂贴住对方前臂，向外一拨 |
| 步法 | 步伐稳重 | 写清每一步落在哪（“左脚踏进半步”） |
| 身段 | 形体姿态的组合 | 关键姿势侧对镜头，只看轮廓也认得出 |
| 套招 / 度招 | 预先编排、排练的对打 | 只在设计时用；提示词里拆成一拍一对接触 |
| 到肉 | 打击感原始、真实 | 受方反应大，配一声闷响 |
| 卖（受方反应） | 受方反应决定观众觉得多有力 | 写受方的位移、对折、离地 |
| 借位 | 从某个角度让拳和脸在画面里重叠，看起来像打中 | 镜头在攻方肩后：拳与对方脸重叠的一瞬，对方头甩向画面右。反复穿模时的备选，待实测 |
| 吊威亚 | 靠钢丝飞 | 写意段写腾空全过程；写实段写“没有飘浮感” |
| 翻跌 | 翻身、跟斗、跌扑 | 写先着地的部位，再滚，再停姿 |
| 硬僵身 | 挨打濒死时直挺挺倒下 | 双腿绷直向后直挺挺倒下，后背先拍地，扬起一圈灰 |
| 甩发 | 甩头发表现情绪 | 停下后头发甩一圈才落 |
| 把子功 | 兵器对打的基本功 | 写持械手、刃线、只用一种出招 |
| 停—爆—停 | 清楚的画面按停、爆发、停排 | 对峙一拍 → 两三下快攻 → 定住（Bordwell 2008） |
| 远景定位 | 适时给远景交代打到哪一步 | 第一镜全景交代两人距离（林魂谈《雾山五行》，界面 2023） |
| 重置节拍 | 30 秒里插一次分开、喘气 | 两人退开，各自喘气，重新起架（seedance.tv 2026-08-29） |

**受击倒地词表**：对折（腹部受击身体折起）、跪倒（单膝或双膝落地）、翻跌（滚一圈卸力）、硬僵身（直挺后倒、背先着地）、滑退（脚底贴地后滑，留痕）。按力量从小到大选，一条视频里不全用最重的。

**动作参考视频（可选，默认不用）**：参考视频的生成更贵，不为它专门去拍或生成。手头正好有武指实拍、预演或动捕片段，而且某场关键打斗反复生成都不对时，才考虑上传，只取编排和节奏，人物外形仍按资产图（CometAPI 2026-08-10；谷垣健治谈 AI 可以先在电脑上试动作，HK01 2026-06-10）。

## 16. 兵器语法：每种兵器怎么动、哪里会错

每种兵器的动作写法各有一套，下面按第三方样本整理（S31，作者称出片好，无对照）。提示词里写“物理”那一栏的意思，“易错”那一栏改成正面约束写一次。

| 兵器 | 招式 | 物理（写进提示词） | 易错 → 正面约束 |
|---|---|---|---|
| 长剑、长刀 | 斜切、回锋、绕侧斩、横挡、贴身压剑 | 握剑的手、肩、腰、腿一起驱动剑锋；格挡后剑身震颤、身体回弹 | 手臂单独挥 → “由腰胯带动肩背和手臂发力” |
| 巨刃、长柄刃 | 撩刃、回马斩、贴地横扫、俯冲下劈、拖刃 | 刃越大，起势越长、惯性越大；收不住时借惯性接下一招 | 挥得和短刀一样快 → 写“刃身沉重，挥出后带着身体转半圈” |
| 长枪 | 突刺、枪杆横扫、枪尾反抽、回枪、旋枪、插枪借支点旋身 | 枪杆受力弯曲后回弹；枪的优势是距离 | 枪被当成棍乱抡 → 写清这一下用的是枪尖、枪杆还是枪尾 |
| 折扇 | 开扇、合扇、翻腕、横扇、挑扇、压扇、扇柄点击 | 扇骨数量、扇面纹样、开合方向固定；扇面受力会微弯后恢复 | 扇子变形、变成别的兵器 → “折扇始终是同一把，开合结构清楚” |
| 流星锤、链类 | 甩出、回收、绕身回旋、贴地拖行、上提、横扫、反抽 | 甩出时链条拉直，回收时成弧线，旋转有离心力；改方向时身体重心跟着变 | 链条忽长忽短、穿过身体 → “链条长度不变，始终在身体外侧” |
| 拳（带能量） | 直拳、双拳夹击、肩撞、硬接武器 | 肩腰腿完整发力链；拳出后手臂后坐、身体前冲 | 拳头和身体脱节 → 写“整个人随拳向前压” |
| 伞刃 | 旋柄、展开、折回、斜挑、下旋斩 | 伞面展开和折回是结构变化，写清现在是开还是合 | 伞面破损形状每镜不同 → 资产设定里写清破损结构 |
| 巨笔、法器 | 提腕运笔、横、撇捺、点、勾、凌空题字 | 每个笔画是一招，笔毫沾墨，笔势不断 | 当棍子挥 → 写成书法笔画 |

## 17. 一场打斗怎么设计（样本归纳）

- **先定谁压谁**：整段谁主动前压、谁边退边控场，在哪一拍换手，一句写进提示词的人物关系部分（“黑衣始终主动前压，巫女边退边控场，第 20 秒起反压”）。
- **先写一行战斗链**：例如“枪线控制 → 抢内圈 → 连续枪剑碰撞 → 黑枪强化 → 红剑觉醒 → 借枪旋转 → 争夺枪杆 → 断枪 → 面具裂痕”。链上最后三四项就是记忆点（数量按戏定）。
- **打法由兵器长短决定**：长兵控距离、逼对手进危险距离；短兵不断抢进内圈，格挡后立刻压枪、闪避后立刻回锋。两人的打法整场不变（第 13 节“两个对手打法不同”）。
- **碰撞的反作用力就是下一招的动力**：被震退时借反震前冲，被撞飞时蹬墙弹回。碰撞之后不停顿。
- **借地形改变轨迹**：踩住正在倒塌的柱子换高度、空中借飞起的碎石换方向、贴着对方武器侧面翻过去落到身后。一场里两三个这样的动作，每个写成“地面 → 借力物 → 空中 → 落点”，不写成普通二段跳。
- **速度有落差**：快 → 更快 → 一下极短看清 → 爆发；整段不均速。低幅度蓄力时人物动作收小，但头发、衣摆、尘土、火焰继续动。
- **场地推进线**：写一条“首位 → 古树 → 岩石 → 崩塌岩壁 → 废墟深处”的推进顺序，每次换位后立刻接新招，不回原位。
- **战损递进**：开场环境完整 → 中段树断石碎 → 后段一片废墟 → 最后一击推到极限；已经坏掉的不复原。
- **破坏阶梯**（第三方样本：碎地砖断柱 → 廊柱斩断台阶崩 → 侧殿坍塌 → 主穹顶神像崩毁，每级对应招式升一个强度层次）：一场戏开头列 3–4 级可破坏物，用文字写，不用代号；每条打斗视频的结束画面写“到了第几级、哪些已经坏了”，下一条原样继承，不回退、不自动复原。
- **回合账（设计时列，不进提示词）**（多份第三方双人打斗样本归纳，适用于整场的回合排法，待出片验证）：
  - 每回合列两栏：攻方形状（点、线、扇、墙、环、网、钳、近身重劈）和守方应对（硬接、卸力、躲开、穿缝、拨开、借力反点）；相邻回合不重样，同一形状第二次出现要升级。
  - 主动权每 2–3 回合换一次手，换手那拍有标记（受方神情或姿态变了），下一招不蓄力直接接上；结果量级拉开：被挡 → 擦过（削断袖片、发丝、袍带，用衣饰记账不用伤口）→ 命中非要害 → 连中 → 被震飞。
  - 危机拍的写法：全场最重一击 → 兵器脱手或几乎脱手、单膝或倒地 → 衣甲崩裂、喘出白气 → 眼神决绝的近景 → 下一拍翻滚抄回兵器、直接反击（最好命中此前埋的点）。样本里这一拍在全段约一半处，五段结构里更靠后，按你的结构定，待验证。
  - 反制从对手的优势来源下手：抢进长兵内圈、卸掉重兵的阻力让其过冲、盯同一处连打三下让兵器裂到断、破坏发力支点；先写对手靠什么占上风，再写这一招拆掉哪一样。
  - 贴身时换接触媒介：兵器互压到最近，下一回合改用剑柄、肘、膝、肩背；一场里最近距离的回合至少换一次，那一回合不用刃口。
  - 兵器和衣甲的状态也递进（剑刃渐红、枪杆弯 → 裂 → 断、肩甲崩一半），写成设定内的阶段，坏了不复原；渐变在视频模型上是否稳定待验证。
  - 距离和高度也画一条曲线（远程 → 近身 → 贴身 → 拉开；地面 → 空中 → 落地）。近战后、终招前可安排一次拉开对视，这一拍不震，只让发丝衣摆、碎屑动，然后蓄力、对冲；只借这个节拍，不借样本“势均力敌、同时开大”的收法。
  - 布阵 → 入阵 → 破阵：一方边移动边留下不散的痕迹围成网或笼，对方闯入受困，下一回合从布阵时留的缺口破开；三回合算一个“转”，放在五段的第二到第三段之间。
  - 不采用：样本里“平手各自离去”的收束（原稿主角赢的打斗走满五段；原稿本身就是平手或败北的，按原稿落点收，见第 13 节）、“地形被双方轮流改写”（只适用属性战）。
- **单人展示没有对手**：命中落点用场景物（石拱门、悬空岩柱、远处石柱），每一击都打在一个看得见的东西上。
- **连招每一下都换东西**：换受击部位、换对方防御的形状（圆盾 → 六边 → 菱网 → 半球）、换运镜方向；最后两下砸在同一处才破（第三方样本：五秒七击、一秒八连拳都这样写）。
- **放完招人不停**：出招的人下一拍就动，跟着刀气往前冲、补砍漏掉的、转向下一个目标；召唤出来的东西成形就开打，不站着看（第三方样本 2 份）。
- **连斩对闪避一一对应**：每一刀配一个闪避，原地留一道残影，下一刀落空正好斩碎那道残影（第三方样本）。

## 18. 人对巨兽

- 巨兽的攻击要有重量，人的闪避要有速度；巨兽每一击都带场景破坏（爪砸碎石板、尾扫断树）。
- 人打巨兽的局部：翼、爪、颈侧、眼睛，一击打一处，受击处写清偏转方向（“左翼被斩得向侧方偏开”）。
- 巨兽会用场景反击：抓断树横甩、抓巨石砸、撞塌岩壁。
- 体型差靠镜头：极端广角压迫感和局部特写（巨兽眼睛、巨拳）交替；人在巨兽身上移动时，写清从哪里上、沿哪里跑。
- 巨兽受击：身体偏转或后退一步、毛发和火焰被冲击掀起、脚下地面碎裂。

## 19. 每拍七问、打法重设计与易错接触

来源：一批 AI 漫剧成片的返修记录归纳。经验是：最容易出错的就是打斗戏和特效戏，原稿写的打法不一定好，可以推翻重来。下面的写法是设计方法，没做过对照实验，不保证提高成功率。

**授权边界**：原稿里打斗的“打法”（谁先出手、用什么招、在哪接住、怎么反制、借什么地形）可以推翻重设计；**不动**的是胜负和落点（第 13 节）、伤势事实和伤侧、人物弧光、作者锁定的台词。重设计的在交付说明里标“打法重设计”，一句写原写法哪一问答不上、新打法怎么答。

**每个关键接触拍先回答七问**（设计时答，提示词里只写看得见的结果；第 1 节五件事是其中第 4–6 问的细化）：

| # | 问 | 答不上的常见成片 |
|---|---|---|
| 1 | 谁想达成什么：逼退、打断、抢位、脱身，还是击倒 | 双方摆架势、互相等招 |
| 2 | 双方相隔多远、各在哪、**面朝哪**（面向单独写，不只写左右） | 背对敌人、对空出拳 |
| 3 | 哪只手、脚或兵器起手，支撑点在哪 | 空挥、无起手的瞬移 |
| 4 | 打哪一处；防守方用什么、在哪接住 | 两拳相碰、拳路读不清 |
| 5 | 接触后力往哪传、谁失去平衡 | 打完没人动 |
| 6 | 受击方怎么位移、落在哪、靠什么停下 | 突然飞走、落点无来源 |
| 7 | 防守或反击怎样利用上一拍留下的破绽，怎样接下一条 | 每拍重新摆姿势、重演起手 |

- **有来有回不是机械对称**：行动要改变对方处境、对方做出有效应对；不为凑次数排成“你一拳我一拳”。
- **金光不代替接触**：先写身体、兵器真实碰在哪，再写能量在那里发生什么。

**易错接触补充**（成片记录，第 1–10 节没写到的）：

| 类型 | 必须交代 | 记录到的硬伤 |
|---|---|---|
| 践踏、范围攻击 | 脚下或范围里的对象是谁、几个；谁在范围外、站在哪；落脚位置 | 本该在范围外的主角混进被踩的人群 |
| 高差动作 | 起点高度和支撑、离开支撑、路径、落点、高度参照物 | 地面角色一下在半空、高低关系颠倒 |
| 兵器（补） | 兵器种类写进主体，每次切镜都核 | 棍变刀刃 |
| 群战（补） | 主角和背景群众身份分开写 | 观众里出现主角复制体 |

**出错先分层，不先怪时长和清晰度**：“480P 算力不够导致打斗出错”这个归因，现有记录里没有对照实验支持。先按这个顺序查：空间是否冲突、接触是否写清、一段里塞了几个互相竞争的任务、对白是否占掉动作时间、资产是否错绑。两三次攻防仍失败，和十秒里塞群战、长对白、变身、大招、坠落是两回事。要拆就按完整因果段拆（A 段攻击和格挡，B 段承接格挡后的位移并反击），不在接触那一下断开；前段落幅和后段起幅对上，不重摆姿势、不重演起手。

## 20. 从优秀 AI 打斗短片里学到的写法

下面来自逐镜拆解一批打斗、特效、运镜都很好的 AI 短片（片源不公开，时间码省略），是前面各节没有的写法。

1. **连击不切镜**：同一机位一镜写完，每下约半秒（举到顶点停一瞬 → 劈下 → 命中 → 马上再举），命中点每次落在画面同一块位置；最后一下举得更高、后仰更深、停得更久，作收尾重击。每下写三层：接触点火星、被打处凹下或碎屑弹起、攻方被反震一弹。
2. **追打落点差半步**：每一击都有落点（插地、火星、地裂），落点总在目标刚离开的位置；被追的一方换着躲（翻滚 → 跳 → 贴地爬 → 再跳），不连续用同一种；最后用对称构图封死（剑笼、四面围住）。
3. **一招之内分快慢**：冲刺快（背景横向拉糊、主体清楚）→ 拉开一镜交代距离 → 迎击 → 接触点慢写约 2 秒（裂纹、碎屑越来越多，脸上眯眼、皱鼻、咬紧）→ 碎裂一闪而过 → 压住对手静约 2 秒 → 爆发。最慢给接触点，最快给碎裂。
4. **小打大的攀爬路线**：钻腿间 → 抓毛或甲缝往上爬 → 兵器插进去当登山杖 → 背上站起 → 砸。每一步落在对方身体的具体部位。
5. **兵器一物两用**：锁链缠楼当荡绳、缠角把自己拉过去；棍子横塞进嘴里卡住对方蓄力；棍尖拖地出火星写重量。
6. **打飞给距离**：打飞后切大远景，人只剩远处一个小点；再接空中翻、落地碎，各一镜。同伴可以在空中接住。
7. **一个动作让整片环境响应**：一踏，泥土草皮像浪一样整片翻起，敌人被当作碎屑卷走。
8. **伤害累积看得见**：剑一把把插在身上越来越多；终结那一击的尺寸是普通攻击的十几倍，落点有冲击环。护罩上的裂纹越来越多，表示快撑不住。
9. **以身挡招、三方向合击**：同伴用身体挡在光束前；三方从三个方向同时打向同一点，中心爆开一圈。
