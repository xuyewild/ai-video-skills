# 风格段写法：视频风格段、资产图风格段与 Midjourney

结论后面的 [Sx] 对应 [sources.md](sources.md)。没有标号的是作者在生产中的判断，按你实际生成的结果改。视频部分以 Seedance 2.5 为例，其他视频模型结构相同，具体写法以该模型官方指南为准。

## 〇、先定风格档案（任何风格都一样）

画风不限：3D 国漫、2D 动漫、厚涂、水墨、彩色漫画、真人都按同一个方法定。风格名只是标签，模型靠看得见的做法区分风格：第三方 casting-lookbook 把风格写成“技法、材质、边缘、色彩”加“造型语言”的指纹 [S13]；Atlas Cloud 也建议 2D 动漫用描线、平涂这类具体写法代替“电影感” [S14]。项目开头和负责人定下五项，写进风格一句话、资产图风格段和视频风格段：

| 项 | 写什么 | 例：3D 国漫 | 例：2D 赛璐璐 |
|---|---|---|---|
| 1 风格名（主锚点） | 媒介加风格，一个主锚点 | 3D 国漫动画 | 2D 日式动画，赛璐璐上色 |
| 2 造型语言 | 头身倾向；眼睛大小和形状；鼻子、嘴怎么简化；头发成束还是一根根；皮肤画到什么程度 | 修长比例；眼睛比真人略大，保留鼻梁；头发成束有体积；皮肤细腻、不画毛孔 | 大眼，鼻子一笔带过；头发成大块；皮肤不画纹理 |
| 3 线条与着色 | 有没有描线、线粗细；平涂、赛璐璐、厚涂还是写实渲染；阴影几层、边缘软硬 | 不描线，柔和渐变着色 | 干净的黑色描线，粗细一致；平涂加一两层硬边阴影 |
| 4 材质 | 皮肤、布料、金属、毛发在这种画法里怎么表现 | 布料有织纹，金属小面积高光 | 布料只画褶线，金属用一块高光色 |
| 5 反向锚定 | 一句，指向最容易漂去的方向 | 不是真人实拍 | 不是 3D 渲染，没有体积光和柔和的渐变阴影 |

- 光不进风格档案：光写在“光线”和“时段与天气变体”，资产图是灰底均匀光。
- Seedance 2.5 默认偏写实 [S4]，非写实风格的第 2、3 项写得最具体，第 5 项指向写实或 3D。
- 第 2 项在 3D 国漫上有没有用还没做过对照：可以拿一个人物，资产图风格段加、不加这一句各出一张，有效再写进项目。
- 表里 2D 赛璐璐那一列是写法示范，作者没有实测；第一次用新风格按四C 走。

## 一、视频风格段（以 Seedance 2.5 为例）

### 放在哪

- 官方基础写法：一句话概述“主体 + 地点 + 事件 + 题材/风格”，再写分镜头，结尾补充贯穿始终的画面细节和氛围 [S1]。风格段放在提示词第一句，光线色调关系在“保持一致”部分再写一次。
- 官方提示词优化 skill 的模板写“画面呈现<视觉风格或情绪>”，并要求长提示词时“压缩重复风格词、重复约束”，不设字数上限 [S2]。所以风格段每条提示词只写一次，不在镜头行里重复。
- 长度：作者定两三句、约 40—80 字。官方没有给数字。

### 写什么

1. 媒介和风格名（风格档案第 1 项），例如 `3D 国漫动画风格`。官方例子里的写法有“顶级3D国漫仙侠”“3D 国漫 CG 仙侠风格”“3D国风漫画” [S1][S3]。
2. 造型和着色（风格档案第 2—4 项，挑最能区分风格的一两样）：比如修长的 CG 比例还是 Q 版（头身数写在资产表，风格段不写数字）、有没有描线、皮肤和布料质感。
3. 一句反向锚定（风格档案第 5 项）。
4. 色彩倾向：主色调 + 肤色保护，一句。
5. 光线基线：有来源、软硬、暗部。
6. 当前时段、天气那一句（从变体表取）拼在后面。
7. 摄影质感（可选）：镜头惯性、运动模糊、景深、空气透视，写成看得见的样子（“镜头有真实的惯性和轻微手持感，高速时有方向正确的运动模糊”）。参考作品可以拿来沟通，进提示词要拆成这类看得见的条件。

不写：色值代码。“8K”“UE5”这类画质引擎词可以加在末尾。

### 渲染风格和战斗演出风格分开写

网上流传的打斗提示词常把“半写实 3D 动画电影感”（渲染）和“日式番剧 sakuga 战斗演出”（演出）混在一句里，再叠上 UE5、8K、masterpiece、ultra-detailed 一串词 [S12]。拆开看：

- **渲染风格**（长什么样）：就是视频风格段，一个主锚点加一两个辅助词，全片不换。英文锚词（anime cinematic CG）不比中文同义写法多出信息，中文提示词就统一用中文。
- **战斗演出风格**（怎么演）：透视、快慢落差、关键帧姿态、镜头跟随，属于动作和镜头，写在模板里可选的“战斗演出风格”一段，只在打斗、大招镜头接在风格段后面。日式作画的“sakuga”写成它的画面意思，不写这个词。
- **画质词和引擎名**（UE5、8K、PBR、masterpiece）：外面说法不一：官方提示词优化 skill 不主动加；Segmind、Venice 说作用很小；出片好的第三方打斗样本几乎都写 [S12]。没有对照实测。可以加在风格段末尾，但代替不了看得见的描述，风格档案五项照写。

### 参考图和文字风格冲突时

- 官方提示词优化 skill 的映射优先级：用户明确指定 > 提示词描述 > 素材内容 > 文件名 > 上传顺序 [S2]。这是素材职责的优先级，不保证文字能压过参考图的画风。
- 官方 2.5 例子里有“生成的视频色温、光影、亮度参考图片中人物和场景”“参考图片 1 的光影和滤镜”的写法 [S1]：参考图会带进光影和色调。
- 2.5 发布稿称画质优化方向是“更接近实拍的影视质感” [S4]。据此判断：2.5 默认更偏写实，非写实风格要在风格段写明，并靠资产图本身的风格。

所以：**参考图为主，文字为辅**。所有资产图用同一份资产图风格段出图，风格一致后再进视频；风格段写明风格名；灰底资产图不承担光线，光线由风格段和变体句给。

## 二、资产图风格段（任何图像模型）

资产图（人物、场景、道具的定妆图）可以用 GPT Image、Midjourney 或别的图像模型出。风格段原样拼进提示词的“风格”行。

### 图像模型怎么读提示词（以 GPT Image 为例）

- OpenAI Codex 官方 imagegen skill 的提示词结构：用途 → 输入图（图一、图二各写作用）→ 主体 → 风格/媒介 → 构图 → 光线 → 色彩 → 材质 → 约束/避免；要求“写短，只补对结果有实质帮助的细节” [S11]。
- 多张输入图按编号说明各自用途；编辑时写明“只改 X，其余不动”，每轮重复不变项 [S11]。

### 写法

- 一两句，风格名打头（如 `3D 国漫动画 CG 风格`），接风格档案的造型、线条着色、材质。默认质感按 3D 和真人写；2D、线稿、水墨这类再写一段 `## 资产图质感`，出图时用它替换质感描述。内容与 Midjourney 段（如写）一一对应，不另起风格。
- 不写时段、天气、环境光、色调滤镜：资产图是灰底均匀光，这些词会把背景和人物染色。
- 不写色值（灰底在资产表里统一写）、不写参数。
- 风格样张：用资产图风格段出一张，负责人认可后作为后续资产图的风格参照图（提示词“参考图”行写“用于：渲染与材质；不采用：人物、服装、构图”）。

## 三、Midjourney 风格段（可选）

只在用 Midjourney 出资产图时写，标题 `## Midjourney 风格段`。

### 版本与功能（官方，2026-10 读）

- V8 alpha 2026-03-17；V8.1 2026-04-14 发布；V8.2 2026-07-24 起为默认版本 [S5][S6]。
- V8.1/V8.2 支持：Style Reference、Style Weight、Style Reference Codes、Image Prompts、Personalization、Moodboards、Raw、Stylize；不支持：Omni Reference（`--oref`）、Multi-Prompting、Quality 参数、Draft Mode。V8.2 的 Edit Model 取代 Omni Reference、Character Reference 和 Retexture [S6]。
- V8 对长而具体的描述跟得更好；`--raw` 去掉默认风格化，更贴文字 [S5][S6]。
- `--sw` 范围 0—1000，默认 100；风格参考只取整体风格（色彩、媒介、质感、光线），不复制物体和人物；文字提示保持简单，避免与参考图冲突的风格词 [S7]。

### 写法

- 一段英文，写渲染和材质：风格名打头（如 `3D Chinese animation (donghua) CG style`），接风格档案的造型、线条着色、材质。
- 不写时段、天气、环境光、色调滤镜。
- 风格参考：先用风格段出一张样张，负责人认可后作为 `--sref` 图；图片链接比风格码耐用——第三方文章称数字风格码绑定生成它的算法版本 [S8]。`--sw` 从 100 起试；样张的颜色可能渗到灰底上，验图时看灰底是否还是资产表那一个灰。
- 参数（`--ar 16:9`、风格参考行）统一加在提示词末尾，风格段里不写参数。

## 四、例子：3D 国漫风常用描述

| 方面 | 中文（视频、资产图风格段） | 英文（Midjourney） |
|---|---|---|
| 风格名 | 3D 国漫动画风格；3D 国漫 CG | 3D Chinese animation (donghua) CG style |
| 人物 | 修长的 CG 人物比例；五官精致 | elongated CG body proportions, refined facial features |
| 皮肤 | 皮肤细腻、略通透，不是塑料光滑 | refined skin shading, subtle subsurface scattering |
| 布料 | 衣料有织纹和厚薄，丝绸柔和反光 | visible fabric weave, soft silk sheen |
| 光影 | 光线柔和有明确来源（只进视频段） | soft directional light（只用于样张，不进资产风格段） |
| 渲染 | 画面干净细腻 | clean sharp render, no film grain |

第三方教程常用“3D写实渲染与国漫仙侠美学”“CG渲染，电影级光影”这类组合 [S9]；其中“8K超高清”“极致画质”不改变画面，不采用。表中英文词是作者的写法，未经大规模实测。

## 四A、风格段的几条通用写法

- **一个主锚点加一两个辅助词**：“3D 国漫动画风格”或“古装真人电影风格”是主锚点，后面只加一两个质感词；词多了画面容易变泛 [S14]。
- **一句反向锚定**：主锚点后加一句“不是什么”。3D 写“不是真人实拍”，真人写“不是 3D 渲染，没有 CG 塑料感”。只写一句，不展开成清单（有人主张只用正向表述，两边说法冲突，所以只留一句）。
- **不同画风的词不混用**：3D 段不写实拍、胶片颗粒；真人段不写 CG、渲染、国漫；2D 段不写体积光、次表面散射、写实皮肤。
- **光色样张**（可选）：每个主要变体用场景资产出一张带光的样张，视频提示词里作为参考图，写“只用于色温、光影、亮度，不采用人物与构图”。官方 2.5 示例就用了一张“色温、光影、亮度参考图” [S1]。灰底资产图照旧，样张另出。效果待实测。
- **对照定稿样张，不对照上一集**：每集增量时拿项目开头认可的样张对照有没有漂，免得一集一集慢慢偏。

## 四B、例子：真人写实

负责人定了真人风格时用这一套，其余结构不变：

- 风格短名：如“古装真人”。风格一句话写成“古装真人电影风格，写实照片级质感”。
- 材质：皮肤写到真实毛孔和细微色差；布料、金属、木石按实物写。
- 镜头质感：可以有细腻胶片颗粒、高光柔和过渡；默认只写“电影胶片质感”，不写胶片规格。负责人点名要强电影质感时，作为“主锚点后只加一两个质感词”的例外，可以再加一段质感词（变形宽银幕感、胶片颗粒、轻微光晕、极浅景深、低饱和只留一点暖色），和一段只列现场声的音效段（逐项写出要有的声音，写明不要配乐、旁白、字幕）；质感词写在视频风格段，不写进资产图。非写实风格不加。
- 资产图风格段：写成定妆照、剧照的样子（“古装定妆照，自然柔光，真实皮肤质感”）。
- 视频风格段示例：

```text
古装真人电影风格，写实照片级质感，不是 3D 渲染。真实皮肤可见毛孔，细腻胶片颗粒，高光柔和过渡；单一主光有来源，暗部保留纹理。
```

依据：Seedance 2.5 官方指南示例“古装悬疑奇幻真人电影风格，电影级写实质感” [S1]。

## 四C、第一次用新风格

3D 国漫和真人之外的风格（2D 动漫、厚涂、水墨、彩色漫画、黏土……）第一次用时：

1. 和负责人定风格名和参考（片名或图，只取画法，不取人物和剧情）。
2. 联网查近期用你的视频模型和图像模型做这种风格的实例和写法，填风格档案五项，来源记进 sources。
3. 可借的起点：casting-lookbook 锚库有水墨、厚涂、线稿、水彩、黏土、二次元 3D 等风格的指纹 [S13]，选到相近的拿来做起点（它用 gpt-image-2 单次测试，换到你的项目要重验）。彩色漫画风可借的做法：颜色按部位分工（大面积主色、对照色、小面积强调色），描线管结构、色面管大关系，非自然色的阴影写成颜料色面，不写成彩灯照射 [S13]。
4. 验证：用资产图风格段出一张定妆，用视频风格段出一段低分辨率短样片，负责人认可才批量用；不认就改第 2、3、5 项再试。
5. 跟着风格改的还有一处：资产图质感（模板可选段）。

## 五、Seedance 2.0 与 2.5 的差异

- 美学差异：2.5 与 2.0 美学风格偏好差异较大，相同参考图与提示词生成的风格明显不同，混用不连贯；要在 2.5 中保留 2.0 风格，官方建议把 2.0 生成的视频作为延长任务输入，输出格式选 MOV [S1]。规则：同一场戏只用一个模型。
- 参考图上限：2.0 全模态参考 0—9 张图片、0—3 段视频、0—3 段音频；2.5 为 0—30 张、0—10 段、0—10 段 [S10]。
- 宽高比：2.0 只有固定 6 档，2.5 支持 [0.4, 2.5] 任意比例 [S1]。16:9 两者都可用。
- 2.0 风格漂向写实更常见：写实参考图加上没强调风格，会漂成真人写实，要加风格约束词，或先把参考图转成目标风格 [S3]。
