# 视觉圣经模板

复制到 `项目名/00_项目/视觉圣经.md`。下面示例是一个虚构的 3D 东方奇幻项目（主角林舟，随身灵狐团子），内容只是写法示范，项目里按剧本和负责人的要求改。`scripts/check_visual_bible.py` 按本页的标题和字段名检查，标题不要改名。

````markdown
# 视觉圣经

风格短名：3D 国漫风
风格一句话：3D 国漫动画，修长比例的 CG 人物配东方奇幻场景，质感干净细腻，整体沉稳偏冷、关键处有暖光。
特效强度：中高；普通招式按基线，招牌大招和全片高潮升一档，同一场有起伏
固定特效：护身符光＝青白色；灵狐狐火＝橙金色

## 色彩
- 主色调：灰青与石青，占画面大部分（天空、远山、石建筑）。
- 暗部：深青灰，不发黑、不偏紫，暗处仍看得清衣服轮廓。
- 高光：偏暖的米白，只出现在受光边缘和金属。
- 肤色：自然暖肤色，冷环境里也不发灰发青。
- 点缀色：朱红，只用在旧印章、血迹、关键道具，小面积。
- 比例：灰青约六成（天空、远山、石墙），暖米白约三成（受光面、木器），朱红约一成。
- 保留色：朱红只给剧情关键物，本集高潮前不出现大面积暖色。

## 配色体系（可选，人物多、阵营多或颜色要讲故事时写）
- 色彩意识形态：灰青＝秩序与压抑；朱红＝血和剧情关键物；暖米白＝人情和安全处。
- 人物与阵营：主角＝白衣配朱红纹，最亮、对比最强；对手阵营＝冷蓝银；群演＝灰青，比主角暗一档、素一档。
- 空间色身份：书院＝灰青石、浅天；荒野＝土褐、暗绿；主角住处＝暖木、烛光。
- 饱和度与明度层次：人物和保留色最饱和，特效次之，环境最素；远景更淡更冷。
- 分离：主角和背景至少在明暗、冷暖、饱和度一项上拉开；同色衣服靠光（亮侧、轮廓光）和站位拉开。
- 同色非保留用途：金属、饰物上的同色写成哑光、偏暗，不发光，和保留色的光分开。

## 光线
- 主光有来源：日景是天光加侧逆光，夜景是月光或火光，室内是窗光或烛火。
- 软光为主，人物脸上明暗过渡柔和；打斗和特效段允许硬光。
- 反差中等：亮部不过曝成白块，暗部保留细节。
- 脸的亮侧永远朝向光源；离火光近的人更亮。
- 场景光影要说得通：光找得到来源（窗、灯、火、天光），方向统一，影子对得上，夜里不会处处亮；非写实风格可以写意（比如更强的轮廓光、带情绪的色光），但不能违和。真人题材一律按现实逻辑。
- 特效光：技能光要照到人物和环境（交互光），写清照亮谁、谁保持原色；大型碰撞可以短暂改变全场的光，峰值后回到本场基线。
- 最暗处是有纹理的深灰，不是纯黑。

## 光型（可选，按场景类型各一行）
| 场景类型 | 主光型和方位 | 明暗（暗部约占画面几成） | 冷暖 |
|---|---|---|---|
| 日景对白 | 斜侧光，太阳在人物斜后方，软光 | 中调，一到两成 | 暖阳对青灰阴影 |
| 密谋、审讯 | 硬侧光或顶光，只有一盏灯 | 暗调，五到六成 | 暖灯对冷暗部 |
| 觉醒、被选中 | 背后光环或一束光只落在主角身上 | 主角亮、周围暗 | 光束暖金，周围冷灰 |

## 材质
- 皮肤：细腻、略带通透感，不是塑料光滑。
- 布料：能看出织纹和厚薄，劲装偏哑光，丝绸有柔和反光。
- 金属与石木：金属小面积高光；石面粗糙低反光；木头有纹理。
- 毛羽：一根根分得清，灵狐的白毛保持纯白，不被环境光染色。

## 镜头质感
- 景深：对白中近景背景适度虚化；有纵深的画面按景深和空气透视远近逐层衰减，主体清楚，远处变淡变虚。
- 锐度与颗粒：画面干净锐利，无胶片颗粒，不加暗角。
- 辉光：只在真实光源和特效周围有轻微辉光。
- 运动气质：摄影机稳、有重量，不晃，不做无来由的高速飞掠。

## 时段与天气变体
| 变体 | 相对基线改什么 | 不能变的 | 给视频的一句 |
|---|---|---|---|
| 日 | 基线 | — | 白天柔和天光从侧后方来，画面灰青为主，人物肤色自然。 |
| 夜 | 整体压暗变冷，主光换成月光或火光 | 肤色可辨，暗部有细节 | 夜晚冷蓝月光为主，火光只照亮附近的人和地面，暗处仍看得清轮廓。 |
| 雨 | 降低反差，地面出现反光 | 白毛不变色 | 阴雨天光线均匀偏灰，地面湿亮反光，雨丝细密。 |
| 回忆 | 褪成暖褐、边缘发虚 | 人物外貌不变 | 回忆画面褪成暖褐色，画面边缘轻微发虚；回到现在时恢复基线。 |

- 室内场景：窗光定方向，光往屋里逐渐变暗，角落可以暗；灯光按灯具定冷暖（烛火、油灯暖，冷白灯不自动写成暖）。
- 时段和天气叠加时，光跟着实际光源走：雨夜沿用夜里的灯和火，不继承白天的天光；屋里看窗外下雨，屋里不下雨、不起雾。

## 色彩脚本（可选，每集一张表）
每集开工前按段落写一张表，写视频提示词时照它定每场明暗冷暖；这里只定表头和规则，示例：

| 段落 | 情绪走向 | 明暗、冷暖、浓淡往哪走 | 保留色出现在哪 |
|---|---|---|---|
| 开场—冲突 | 压抑 → 爆发 | 偏暗偏冷 → 局部暖光 | 朱红第一次出现在旧印章上 |

## 禁止项
- 不变成真人写实或 2D 平涂。
- 不出现无来源的彩色光、整片染色。
- 肤色不发灰、发青、发荧光。
- 人物眼睛不发光（除非剧本写明）。
- 人物不画成网红脸、精修妆、塑料皮。
- 画面不出现字幕、水印、logo。

## 视频风格段

```

## 战斗演出风格（可选，有打斗的项目写）
```text
高预算动画电影的战斗演出：透视夸张，快慢落差大，关键动作的姿态夸张但看得清，镜头跟着动作走。渲染质感不变，仍按上面的风格段。
```

## 尺度基线

- 比例句：林舟身高 182 厘米；团子站直约 40 厘米，头顶到林舟膝盖，蹲在肩头时身子约占半个肩宽。
````

## 各段写法

| 段 | 写法 | 不写 |
|---|---|---|
| 风格短名 | 两到六个字；资产表 `风格基线：` 行括号前逐字相同 | 长句、括号说明（括号说明写在资产表那行后面） |
| 风格一句话 | 媒介 + 渲染质感 + 整体气质 | 剧情、人物名 |
| 固定特效 | 跨集固定、每集都出现的特效每个写死一种颜色：`名字＝颜色`，多个用“；”隔开，没有写“无”。提示词写到它时颜色逐字照抄 | 按场次变色；同一特效两种说法（“青白色”“淡青色”） |
| 特效强度（可选） | 全片基线和升档规则，一句 | 每个招式的具体效果 |
| 色彩 | 五行：主色调、暗部、高光、肤色、点缀色；写颜色和面积。再写主、次、点缀大约的比例（如六三一），每种颜色写清来自什么光源、落在什么表面；点缀色定成“保留色”，只给剧情关键物，写明什么时刻才出现 | 一一对应的套色（“紧张就变红”） |
| 配色体系（可选） | 色彩意识形态（每个颜色在本片代表什么、给谁用）、人物与阵营识别色、空间色身份、饱和度与明度层次、主体怎么和背景分开、保留色的同色用途怎么区分；只写本片的取舍，通用做法见 [color-craft.md](color-craft.md) | 跨项目的通用色彩知识；色值进视频风格段 |
| 色彩脚本（可选） | 定表头和规则；每集按段落写情绪走向、明暗冷暖浓淡往哪走、保留色在哪出现；做法来自皮克斯的色彩脚本 | 每个镜头的色值 |
| 光线 | 主光从哪来、软硬、反差、暗部；加三条可以逐镜检查的规则：亮侧朝光源、离光源近的更亮、暗部是有纹理的深灰不是纯黑 | 某一镜的布光方案 |
| 光型（可选） | 按本项目常见的场景类型各一行：主光型和方位、明暗（暗部约占画面几成，暗部仍有纹理）、冷暖 | 某一镜的布光方案；没有来源的光 |
| 材质 | 本项目常见的四五种材质 | 具体某个道具的结构（归资产表） |
| 镜头质感 | 景深倾向、锐度、颗粒、辉光、运动气质 | 具体运镜 |
| 时段与天气变体 | 只建剧本真实出现的；“给视频的一句”可直接拼在视频风格段后。特殊风格段（回忆、梦境、幻境）写 1—2 条看得见的规则（如“褪成暖褐、边缘发虚”），并写什么时候回到基线 | 一场戏一个变体 |
| 禁止项 | 五到十条，可检查 | 几十条同义句 |
| 资产图风格段 | 一两句；只写渲染和材质；原样拼进图像提示词“风格”行 | 时段、天气、场景光、色调滤镜（人物、道具图是灰底均匀光；场景图的光影按变体另写）；色值、`--` 参数 |
| 资产图质感（可选） | 2D、线稿、水墨这类风格写一句：阴影几层、边缘软硬、布料和金属怎么画、皮肤画不画纹理 | 光、时段、色值 |
| Midjourney 风格段（可选） | 用 Midjourney 时才写；一段英文，内容与资产图风格段对应 | 同上；参数写在下一行“风格参考” |
| 风格参考（Midjourney 段内） | `无`，或 `--sref <样张图链接> --sw <0—1000>` | 多个互相冲突的样张 |
| 视频风格段 | 两三句中文、约 40—80 字，含一句反向锚定 | 色值代码、“电影感”“高级感”这类空词 |
| 战斗演出风格（可选） | 一两句：动作和镜头怎么演，不写渲染；只在打斗、大招镜头接在视频风格段后 | 和风格段混写 |
| 尺度基线 | 每个主要人物、生物一行：身高或体长写数字（厘米、米），常一起出现的写相对位置（蹲在肩头时占肩宽多少）；最后一行“比例句”给视频提示词逐字照抄。有资产表时数字与它一致，改一处同步改 | 只写“很小”“到膝盖”这类没有数字的话 |
| 与资产表对应（可选） | `风格基线：`、`灰底：` 两行；`风格基线` 括号前与风格短名逐字一致 | — |

## 与资产表的对应

- 资产表表头写 `风格基线：<风格短名>（细节见 视觉圣经.md）`，括号前必须与“风格短名”逐字一致，这样拼提示词的脚本或人只取括号前那几个字。
- 图像提示词：“风格：<风格短名>；<资产图风格段>”，再接外貌、比例、构图、灰底。
- 用 Midjourney 时：`<风格短名> production asset sheet of …` 后接 Midjourney 风格段，再接外貌、比例、构图、灰底；“风格参考”不是“无”时，把那行参数放在 `--ar 16:9` 后面。
- 资产表 `灰底：` 与本文件“与资产表对应”的灰底一致。
- 改了风格短名或资产图风格段：资产表同步改；已认可的图是否重出由负责人定（只改措辞不重出）。

## 更新

- 新时段、天气或新地点类型：在变体表追加一行。
- 风格本身改了（例如从偏冷改偏暖）：改对应段，聊天里一句话说明影响哪些已出的图和镜头。
- 不留修订号、历史版本；需要历史看版本管理。
