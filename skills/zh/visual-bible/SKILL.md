# 视觉圣经

用 AI 生成一部片子，最常见的毛病是“每一条都好看，放在一起不像一部片”：这一条偏冷、下一条偏暖，人物这集是 3D、下集滑向真人，夜戏处处是亮的。视觉圣经就是一份一到两屏的短文件，把全片的画风、色彩、光线写死，再给出两段可以直接粘贴进提示词的风格段，让每一次生成都从同一个底子出发。

它来自半年 AI 漫剧生产（图像模型出资产图，Seedance 2.5 出视频）。方法与模型无关，Seedance 的具体写法单独标出。

## 1. 做什么，不做什么

产出一个文件，建议放在 `00_项目/视觉圣经.md`（英文项目用 `00_project/visual-bible.md`）。

| 谁读 | 读哪段 | 用来干什么 |
|---|---|---|
| 写图像提示词的人或 AI | 风格短名、资产图风格段（用 Midjourney 时读它那一段） | 人物、场景、道具图提示词的风格部分 |
| 写视频提示词的人或 AI | 视频风格段、当前变体那一句、色彩、禁止项、尺度基线 | 每条视频提示词的第一句和“保持一致”部分 |
| 负责人（导演） | 全文 | 一屏看完、拍板 |

不做：镜头、构图、运镜；人物、场景、道具的具体外貌（写在你的角色或资产表里）；声音；剧情。

## 2. 什么时候写、什么时候改

- **项目开头建底子**：读剧本，列出真实出现的地点类型和时段、天气，按模板写。
- **之后只做增量**：每集（或每批）开工前看一眼有没有变体表里没有的时段、天气、地点类型或特殊风格段（回忆、梦境、幻境）。有就加一行，只写相对基线改了什么；没有就不动，回一句“本集无新增变体”。
- **风格底子不按集改**：风格一句话、色彩、材质、镜头质感和两个风格段要改，先问负责人。改了以后从下一个还没生成的镜头起用新文字；已认可的图只因措辞调整不重出，风格本身变了才重出。

## 3. 输入

- 负责人给的风格要求、参考片名或参考图。参考只取色彩、光线、材质、质感，不取人物和剧情。
- 剧本里反复出现的地点类型和时段、天气（日、夜、雨、雪、室内烛光……），只为真实出现的建变体。
- 有资产表（角色、场景、道具登记表）时，它的“风格基线”“灰底”两行。

风格没定先问负责人。定了名字缺细节，按 [style-writing.md](references/style-writing.md) 第〇节“风格档案”五项补齐，交付时说清“这几项是我定的”。不因缺色值、缺参考片而停下。

## 4. 文件格式

模板与每段写法见 [template.md](references/template.md)。固定顺序：

1. `风格短名：`——两到六个字，如 `3D 国漫风`、`2D 赛璐璐`。有资产表时原样写进它的 `风格基线：` 行。
2. `风格一句话：`——媒介 + 渲染质感 + 整体气质，一句。
3. `固定特效：`——跨集反复出现的特效（某人的护体光、一条贯穿全片的魔法线）每个写死一种颜色：`名字＝颜色`，多个用“；”隔开，没有写“无”。可选：`特效强度：` 写全片特效的基线强度。
4. `## 色彩`——主色调、暗部、高光、肤色、点缀色各一行，加主次比例和保留色。配色体系见 [color-craft.md](references/color-craft.md)。
5. `## 光线`——主光来源逻辑、软硬、反差、暗部留多少细节。光影和色彩常常比场景本身更重要：不论什么画风，光都要找得到来源、方向统一；非写实可以写意，但不能违和。
6. `## 材质`——皮肤、布料、金属、石木、毛羽等本项目常见材质怎么呈现。
7. `## 镜头质感`——景深倾向、锐度、颗粒、辉光；摄影机运动的气质（稳、重、轻），不写具体运镜。
8. `## 时段与天气变体`——表格：变体｜相对基线改什么｜不能变的｜给视频的一句。
9. `## 禁止项`——五到十条，写真正会跑偏的方向。
10. `## 资产图风格段`——一两句，只写渲染与材质，不写环境光和时段（人物、道具图一般是灰底均匀光；场景图的光按变体另写）。
11. `## 视频风格段`——两三句中文：风格 + 色彩倾向 + 光线基线，放在每条视频提示词的第一句。
12. `## 尺度基线`——主要人物、生物每个一行身高或体长数字，最后一行“比例句”给视频提示词逐字照抄。
13. （可选）`## 与资产表对应`——两行：`风格基线：<风格短名>（细节见 视觉圣经.md）`、`灰底：<色值>`。

可选段：`## 配色体系`、`## 光型`、`## 色彩脚本`、`## 战斗演出风格`、`## Midjourney 风格段`、`## 资产图质感`，写法见模板。

整份文件控制在一屏到两屏。不写内部编号、修订号、状态字段；要历史看版本管理。

## 5. 风格段怎么写

风格档案、细则和各风格例子见 [style-writing.md](references/style-writing.md)，来源见 [sources.md](references/sources.md)。要点：

- **风格写成看得见的做法**：模型靠“有没有描线、阴影几层、皮肤画到什么程度”区分风格，不靠风格名本身。一个主锚点加一两个辅助词，再加一句“不是什么”（反向锚定）。
- **视频风格段**：两三句、约 40—80 字，每条提示词只写一次，不在每个镜头重复。Seedance 2.5 官方结构是“一句话概述（主体 + 地点 + 事件 + 题材/风格）→ 分镜头 → 结尾补充贯穿始终的氛围”，风格段就放在开头那句里。不写色值代码。
- **资产图风格段**：一两句，风格名打头，接造型、线条着色、材质。不写时段、天气、环境光、色调滤镜，这些词会把灰底和人物染色。不写色值和参数。
- **Midjourney（可选）**：用它出图时另写一段英文，内容与资产图风格段对应；参数放在下一行“风格参考”，不写进风格段。
- “8K”“UE5”这类画质词可以加在末尾，但代替不了看得见的风格描述。
- 参考图和文字冲突时，参考图通常赢。所以先用资产图风格段出一张样张，负责人认可后当后续所有资产图的风格参照，风格一致了再进视频。

## 6. 流程

1. 读剧本，列出真实出现的地点类型和时段、天气。
2. 按模板写初稿；变体只写相对基线改了什么。
3. 写风格段，自查：视频风格段没有色值代码；资产图风格段（和 Midjourney 段，如写）没有时段、天气、场景光。
4. 跑检查脚本（只查格式，不评判风格好坏）：

   ```bash
   python3 scripts/check_visual_bible.py 视觉圣经.md [--registry 资产表.md] [--prompts 提示词.md ...]
   ```

   `--registry` 核对资产表的风格基线和灰底；`--prompts` 检查提示词里写到固定特效时颜色是否照抄（只提醒）。
5. 交给负责人看一屏，改完即定稿。要样张时，用资产图风格段出一张，认可后作为风格参照图。

## 7. 下游怎么用

- **图像**：提示词“风格”行 = 风格短名 + 资产图风格段，再接外貌、比例、构图、背景。
- **视频**：每条提示词第一句 = 视频风格段 + 当前变体那一句；“保持一致”写一次光线色调关系和三到五个本场颜色锚点；与本条相关的禁止项改成正面写法放进去；同框的人物和生物逐字照抄“比例句”。不写“参考视觉圣经”“同上”，模型看不到这个文件。
- **对照定稿样张，不对照上一集**：每次增量拿项目开头认可的样张对照有没有漂，免得一集一集慢慢偏。

## 8. 换视频模型时

不同模型（包括同一家的不同版本）美学偏好差别很大，同一场戏不混用两个模型。换模型后先用风格段各出一条短样片给负责人看，再批量。Seedance 2.0 与 2.5 的具体差异见 style-writing.md 最后一节。

## 9. 交付

- 视觉圣经文件（按模板）。
- 聊天里两三行：定了什么风格、哪几项是自己定的、资产表是否已同步。
